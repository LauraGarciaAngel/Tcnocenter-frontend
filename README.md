# Tcnocenter E-commerce

> **Estado: En fase de desarrollo.**

## Estructura del proyecto

```text
Tcnocenter-frontend/
├── assets/
│   └── images/
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── index.html
└── README.md
```

- `html/index.html`: página principal y estructura del contenido.
- `css/styles.css`: estilos de la aplicación.
- `js/main.js`: comportamiento e interactividad.
- `assets/images/`: imágenes y recursos visuales.

## Equipo de desarrollo

Estamos trabajando en el desarrollo del e-commerce de Tcnocenter, una plataforma pensada para ofrecer a los clientes una experiencia de compra en línea clara, práctica y accesible.
